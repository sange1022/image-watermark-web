# 实况照片批量导出设计

## 目标与边界

在现有网页和 Windows 桌面版中增加独立的实况照片导出，不改变普通图片导出。用户已接受传输路径：导出配对文件，在 Mac「照片」中一起导入，再从「照片」隔空投送至苹果设备。

交付不能把普通 MP4、GIF 或没有配对元数据的 JPG/MOV 称作实况照片。不承诺 QQ、微信、文件分享或锁屏壁纸兼容性。无需上传用户图片，不自动操作用户的照片图库。

## 界面与操作

- 在现有设置区域增加「实况照片」分组，不增加单独的编辑页面。
- 每张图独立保存启用状态与动画选项，默认关闭；选择图片后可启用。
- 提供「应用到全部」操作，将当前动画和启用状态复制到现有列表。
- 动画选项：缓慢放大（默认）、缓慢缩小、左右轻移、轻微摇晃。固定 3 秒、30 帧每秒，不提供复杂时间轴。
- 启用后可播放/停止当前图片的动画预览，不改变原有裁剪拖动行为。
- 独立「导出实况照片」按钮，仅处理已启用的图片，并显示数量；原「导出」保持静态图片行为。
- 批量任务提供进度、取消与逐项失败信息；已有成功项不因后续失败被丢弃。

## 图像与动画

复用当前裁剪、调色、LUT、清晰度和纹理处理结果。动画作用于处理后的照片，水印最后叠加并保持位置稳定。使用小幅运动与必要的边缘放大，避免露出黑边。

实况视频最长边不超过 1920 像素，不放大小尺寸原图；宽高满足编码要求。静态封面使用同一合成流程生成的中间帧，与视频 1.5 秒位置一致。普通图片的尺寸、格式和命名设置不受实况视频限制影响。

## 技术结构

- 独立动画模块：计算平移/缩放参数，同一函数用于预览和导出。
- 独立编码模块：优先采用浏览器 WebCodecs H.264 编码和成熟的 MOV 封装库，网页与 Electron 共用。开始前探测编码支持；不支持时明确报错，不以其他格式冒充实况。
- 独立配对模块：给 JPEG 写入 Apple MakerNote 标识，给 MOV 写入一致的 content identifier 及中间帧 timed still-image-time 元数据轨。
- 以 macOS 的 PHLivePhoto 资源加载验证作为配对实现的验收门槛。若现有封装库不能写入所需轨道，先验证最小专用元数据适配层，再接入批量界面；未经验证的输出不发布为可用功能。
- 每次导出为每张图生成唯一标识，不复用其他图片的配对标识。

## 保存与传输

每张图输出同名 JPG 和 MOV，两者视为一个保存单位。沿用不含下划线的命名规则，同名冲突时对整对文件统一编号，不覆盖已有文件。保存失败要清理当前任务创建的不完整配对，不删除用户原文件。

没有目录保存能力时下载 ZIP，有目录能力时写入选择的目录。ZIP 内附简短导入说明：解压后一起选中 JPG 和 MOV 导入 Mac「照片」，确认 LIVE 标识后从「照片」隔空投送。下载 ZIP 本身不会在 iPhone 中自动变成实况照片。

## 验证与交付

1. 单元测试覆盖动画边界、尺寸取整、UUID 配对、元数据轨时间、命名冲突及取消。
2. 浏览器测试覆盖单张启用、多张不同动画、批量应用、预览、ZIP 导出及原静态导出回归。
3. 检查视频时长、帧数、封面与视频中间帧一致性，以及水印和调色效果。
4. 在本机用 Apple Photos 框架加载导出配对，验证实况资源识别，不向用户图库写入测试图片。
5. 在 Windows 打包测试中覆盖实况导出并生成更新安装包；网页部署后检查线上页面。
6. 明确区分自动化验证与真实 iPhone AirDrop 验证。若未取得真实设备结果，交付中注明尚待用户设备确认，不声称已完成实机验证。

## 本次不做

原始 iPhone 实况资源编辑、音频配乐、自定义动画时间轴、自动导入系统图库、锁屏壁纸专用元数据、任何服务端图片上传。
